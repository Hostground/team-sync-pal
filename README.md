# Team Sync Planner

Ik wil een planning systeem maken om zelf te hosten op cpanel server. Dus we maken ook een PHP versie met MySQL schema. Het systeem bevat een beheerder, management en medewerkers. Als iemand van het management een nieuwe activiteit plant krijgt de gekozen medewerker daar een melding van. Deze bevestigd of weigert deze binnen de instelbare tijd.
